# 📚 أرشيف الذكي — تحويل الأوراق المصوّرة إلى PDF + قاعدة بيانات + أسئلة وأجوبة بالاستشهاد

تطبيق Streamlit كامل يقوم بـ:
1. **رفع صور الأوراق** → تحويلها تلقائياً إلى ملفات PDF (في مجلد `data/pdfs/`)
2. **استخراج النص** من كل صفحة باستخدام OCR (يدعم العربية + الإنجليزية)
3. **تخزين النصوص** في قاعدة بيانات SQLite + فهرس بحث دلالي (FAISS) لتسجيل موقع كل فقرة (الملف + رقم الصفحة)
4. **الإجابة عن الأسئلة** بالبحث الدلالي، والاستشهاد بنص الفقرة المصدر كاملاً.

---

## 1) التثبيت

```bash
# مكتبات بايثون
pip install -r requirements.txt

# محرك Tesseract OCR (حسب نظام التشغيل)
# Ubuntu/Debian:
sudo apt install tesseract-ocr tesseract-ocr-ara tesseract-ocr-eng
# macOS:
brew install tesseract tesseract-lang
# Windows: حمّل المثبّت من https://github.com/UB-Mannheim/tesseract/wiki
```

## 2) تشغيل نموذج اللغة (مطلوب للإجابة عن الأسئلة)

اختر أحد الخيارين:

**الخيار أ — Ollama (محلي، مجاني):**
```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.1:8b
```
ثم اترك الإعدادات الافتراضية في الشريط الجانبي (`http://localhost:11434`).

**الخيار ب — أي API متوافق مع OpenAI** (OpenAI, Groq, OpenRouter...):
ضع المفتاح واسم النموذج في الشريط الجانبي.

## 3) التشغيل

```bash
streamlit run app.py
```

---

## آلية الاستشهاد الدقيق

- يقسم التطبيق نص كل صفحة إلى فقرات (Chunks) ويحفظ لكل فقرة: **نصها، اسم الملف، ورقم الصفحة**.
- عند السؤال، يجلب أقرب 4 فقرات دلالياً ويعطيها للنموذج اللغوي مع تعليمات صارمة:
  > "أجب فقط من النصوص أدناه. أرفق بعد كل جملة الاستشهاد بصيغة [المصدر: الاسم — صفحة X]."
- تُعرض الإجابة ثم **قائمة المصادر**: نص كل فقرة مستشهد بها كاملاً + اسم الملف ورقم الصفحة، لتتحقق بنفسك من الدقة.
