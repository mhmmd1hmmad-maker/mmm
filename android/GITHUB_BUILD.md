# 🚀 تحويل المشروع إلى APK عبر موقع ويب (بدون برامج على جهازك)

## الطريقة: GitHub Actions (مجاني تماماً)

GitHub يبني ملف APK **تلقائياً على سيرفراته** بعد رفع المشروع — لا تحتاج Android Studio ولا أي تثبيت.

### الخطوات (10 دقائق):

**1) أنشئ حساباً على [github.com](https://github.com) (مجاني)**

**2) أنشئ مستودعاً (Repository) جديداً:**
- اضغط زر ➕ ثم `New repository`
- الاسم: `smartarchive` — اجعله **Public**
- **لا** تفعّل «Add a README»

**3) ارفع ملفات المشروع عبر الويب (بدون Git!):**
- افتح المستودع ← زر `Add file` ← `Upload files`
- اسحب **محتوى مجلد `android/`** فقط (كل الملفات والمجلدات كما هي، بما فيها مجلد `.github`)
- اضغط `Commit changes`
> 💡 لتظهر المجلدات المخفية (`.github`, `.gitignore`) اضغط Ctrl+H في نافذة اختيار الملفات (Windows) أو Cmd+Shift+. (macOS)

**4) انتظر البناء:**
- اذهب إلى تبويب `Actions` — ستجد وظيفة `Build APK` تعمل
- بعد ~5 دقائق (أول مرة) ستظهر علامة ✅ خضراء

**5) حمّل الـ APK:**
- اضغط على اسم الوظيفة (`Build APK`)
- في الأسفل ستجد قسم `Artifacts` ← اضغط `SmartArchive-APK`
- سيُحمَّل ملف ZIP يحتوي `app-debug.apk` — انسخه للهاتف وثبّته
> فعّل «التثبيت من مصادر غير معروفة» عند طلب الهاتف

### ⚠️ مهم جداً — ضبط عنوان الخادم قبل البناء:
الـ APK الافتراضي يتصل بـ `http://192.168.1.5:8000`. غيّره **قبل** رفع المشروع:
1. في `MainActivity.kt` ← سطر `private val SERVER = ...`
2. في `res/xml/network_security_config.xml` ← سطر `<domain ...>`
استبدل `192.168.1.5` بـ IP جهازك الذي يشغّل خادم FastAPI.

### بناء نسخة جديدة بعد أي تعديل:
كل مرة ترفع فيها تعديلاً على الملفات (via web) يبدأ البناء تلقائياً، وتحصل على APK جديد من تبويب Actions.

## بدائل أخرى (اختيارية):
- **Codemagic** ([codemagic.io](https://codemagic.io)): 500 دقيقة بناء مجانية شهرياً — تربط حساب GitHub نفسه ويبني APK بضغطة زر.
- ⚠️ مواقع «صانع التطبيقات» العشوائية (AppsGeyser وغيرها) **لا تقبل** مشاريع Kotlin المصدرية — لا ترفع ZIP لها، فلن تعمل ولقد تعرض مشروعك للسرقة.

---

## لا تنسَ الخادم! 📡
الـ APK وحده لن يعمل بدون الخادم — شغّل `backend/` على كمبيوترك (راجع README_ANDROID.md) وكن على نفس شبكة Wi-Fi.
